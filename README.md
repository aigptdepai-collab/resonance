# Resonance

**Feel the frequency. Break the pattern.**

A polished mobile-first puzzle game. Tap crystals to send energy pulses across the grid. Charge matching colors, create combos, and clear the board.

## Features

- Unique **Pulse** mechanic (not another block or water sort clone)
- Satisfying particle effects & glow
- Gravity after clears
- Multiple levels with increasing difficulty
- Full **English + Persian** support
- Beautiful dark neon UI
- Works great on mobile browsers

## How to Play

1. Tap any crystal
2. A pulse spreads in four directions
3. Same-color crystals get charged
4. Charge 3 or more of the same color → they clear
5. Clear most of the board before running out of moves

## Play Now

Open `index.html` in any modern browser (Chrome / Safari recommended).

## Controls

- Tap / Click → Send pulse
- Hint button → Visual suggestion
- Restart → Reset current level
